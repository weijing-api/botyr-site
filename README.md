# 爆单短视频

这是一个已完成的本地商家短视频获客 MVP：首页、免费选题生成器和移动端样式均已可用。

## 本地预览

直接双击打开 `index.html`，或在当前目录运行：

```powershell
python -m http.server 8080
```

随后访问 `http://localhost:8080`。

## 上线前你需要提供的三项资料

1. 品牌主体（个人或公司）和一个可购买的域名。
2. 用于接收咨询的微信二维码或企业微信。
3. 收款方式（微信/支付宝商家码，或第三方支付服务）。

网站的定位、服务文案、价格建议和免费选题体验已按本地商家获客场景完成；后续只需把真实咨询入口和收款接入即可开始测试获客。
